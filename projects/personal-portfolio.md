# personal-portfolio · 本作品集仓库

> 路径：`../`（即个人主页仓库）
> 一句话：**我的技术作品集本体**——学习笔记、项目、经验贴、兴趣、简历模板的统一入口。

---

## 它包含什么

- 前端作品集（React + Vite + Tailwind）：`src/`、`index.html`、`public/`
- 面试物料：`面试物料/` 下的项目介绍、技术沉淀、题库
- 学习路线：`LEARNING_PATH.md`、12 周笔记
- 外部学习资源（已克隆）：`X-Plore-notes/`、`X-Plore-learn-projects/`
- 衍生作品集：`xtnotes/`（本目录的上级说明）

## 为什么单独开 xtnotes

`personal-portfolio` 偏「主页 + 面试物料」，而 `xtnotes` 偏「纯知识整理与经验贴」（仿 lvynote 风格），两者解耦：
- 主页负责「展示」
- xtnotes 负责「沉淀」

> 你正在看的这份 README 就在 `xtnotes/` 里。

## 技术栈

- 构建：Vite + React + TypeScript + Tailwind
- 部署：Vercel（`vercel.json`）
- 文档：Markdown 为主，后续可接静态站点生成器
