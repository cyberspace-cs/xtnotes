# LeetCode 科学刷题经验

> 关键词：**别盲目刷，先诊断，再定点突破。**

---

## 1. 我踩过的坑

- ❌ 按题号顺序刷：简单题刷一堆，难的跳过，薄弱点永远在。
- ❌ 只刷不复盘：做对的题隔周就忘，错题原地踏步。
- ❌ 不看掌握度：以为刷了 300 题就稳，一考就露怯。

## 2. 我的方法（也是 shuati-coach 的设计来源）

### 2.1 先诊断薄弱点
把做过的题按**知识点**聚合（数组/链表/DP/图/数学…），算出每个模块的：
- 正确率
- 平均耗时
- 错题频次

→ 输出「薄弱模块 Top3」，这就是本周重点。

### 2.2 错题本 ≠ 抄题
错题本存的是**错因标签**：
- 思路错（没想对方向）
- 边界错（空/溢出/越界）
- 模板错（二分/并查集写错）
- 复杂度错（暴力没优化）

下次同类题直接调出历史错因，避免重蹈。

### 2.3 计划要可执行
冲刺计划 = 薄弱模块 + 每日题量 + 复盘节点，输出成 JSON 让 Agent 跟踪：
```
{ focus: ["DP", "图论"], daily: 5, review_every: 3 }
```

### 2.4 用 Agent 当陪练
- `diagnose`：SQL 聚合算薄弱度（0 token，秒回）
- `rag_qa`：基于知识点库答疑，标注引用 [n]，防幻觉
- `reflect`：规则生成跟进建议

## 3. 量化收益（给自己定的指标）

| 指标 | 目标 |
|------|------|
| 薄弱模块正确率 | 从 <60% → >85% |
| 复盘覆盖率 | 错题 100% 打标签 |
| 周刷题量 | 30-40（质量优先） |

## 4. 给后来者的 3 句话

1. **先诊断再刷**，方向比数量重要。
2. **错题本存错因不存题**，复用性强。
3. **让 Agent 干聚合/统计的活**，人只做「想思路」。
