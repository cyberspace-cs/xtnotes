# 牛客面试备战经验

> 牛客（nowcoder）是国内校招/社招笔试面试的主战场。这里记我的备战套路。

---

## 1. 笔试（算法岗）

- **题型分布**：选择（CS 基础）+ 编程（2-3 道，难度递增）。
- **我的策略**：
  - 选择题用「八股速记」扫一遍（OS / 网络 / 数据库 / 计组）。
  - 编程题**先写暴力保底分**，再想优化——交卷前能过样例就有分。
  - 熟悉牛客的**在线判题环境**（输入用 `sys.stdin`，别卡在 IO）。
- **坑**：本地能跑、牛客 TLE——大概率是复杂度没优化或用了慢的输入方式。

## 2. 面试（技术面）

### 2.1 八股怎么准备
- 按主题建卡片：**LLM 推理优化 / Agent 架构 / RAG / 量化 / 分布式**。
- 每道题准备「30 秒版 + 5 分钟版」两套说法。
- 别背定义，背**公式 + 量化收益 + 自研案例**。

### 2.2 项目复盘（最重要）
面试官最爱追问项目，我准备了「项目三问」：
1. 解决什么问题？→ 一句话锚点
2. 关键技术怎么做的？→ 画得出架构图
3. 量化收益？→ 压缩比 / 加速比 / 精度保持

> 我的项目素材见 [projects/](projects/README.md)：Audit-AIOPS、Unified-Audit-AIOPS、shuati-coach。

### 2.3 手撕代码
- 先确认**输入输出**和**边界**，再写。
- 边写边说思路（面试官要的是过程）。
- 写完自测 1-2 个用例，别急着交。

## 3. HR 面 / 反问

- 准备「为什么选我们」「职业规划」的标准答案。
- 反问要有质量：团队在做的方向、模型落地规模、技术栈演进。

## 4. 我的备战时间表（供参考）

| 阶段 | 时长 | 重点 |
|------|------|------|
| 基础扫盲 | 2 周 | 八股卡片 + LeetCode 诊断 |
| 项目打磨 | 2 周 | 项目三问 + 架构图 |
| 模拟面试 | 1 周 | 录音自讲 + 找人 mock |
| 冲刺 | 1 周 | 错题回顾 + 状态调整 |

## 5. 一句话

> 面试不是考你会多少，是考你能**讲清楚**多少。把项目讲成故事，把八股讲成公式。
