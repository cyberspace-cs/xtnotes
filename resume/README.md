# 简历模板（resume/）

> 可直接套用的结构与话术。原则是：**量化收益 + 技术深度 + 项目故事**。

---

## 1. 简历结构模板

```
【基本信息】姓名 / 联系方式 / GitHub / 博客
【求职意向】AI Agent 工程师 / LLM 推理优化
【核心技能】
  - 语言：Python / TypeScript
  - 框架：LangGraph / FastAPI / React
  - 方向：Agent 编排、LLM 推理优化（蒸馏/量化/投机解码/并行）、RAG
【项目经历】（STAR：情境-任务-行动-结果）
  - 每个项目 3 行：做了什么 / 关键技术 / 量化收益
【其他】开源 / 博客 / 竞赛
```

## 2. 项目描述话术（可直接改）

### Audit-AIOPS
> 独立实现端到端模型压缩流水线（蒸馏→剪枝→INT8 量化→投机解码→并行）。**98% 稀疏精度不掉 1pt，叠加 INT8 体积压 50×+；7B 模型 INT4 + 4×4 并行后单卡 1.4GB**，可跑消费级显卡。

### Unified-Audit-AIOPS
> 构建企业级审计运维 Agent：意图识别→工单拆单→审批路由→RAG 问答。**双层 Agent 架构，无 API Key 时规则降级零成本跑通全链路；组合缓存（精确+语义）命中率与省时全可观测**。

### shuati-coach
> 用 StateGraph 搭建刷题教练 Agent（诊断/错题本/计划/RAG 答疑）。**多厂商 LLM 注册表一键切换；结构化输出用 Function Calling 虚拟工具范式，比 json_object 更稳；7 项推理优化（KV 缓存/压缩/投机解码/蒸馏…）**。

## 3. 核心技能写法

不要写「熟悉 Python」，写「能用 Python 实现 LLM 推理优化流水线，含蒸馏/量化算子」。
不要写「了解 Agent」，写「设计过 ReAct/StateGraph 编排，落地多厂商路由与 MCP 工具桥接」。

## 4. 30 秒电梯陈述（面试开场）

> 「我专注 AI Agent 与 LLM 推理优化。做过把 7B 模型压到单卡 1.4GB 的压缩流水线，也搭过企业级审计 Agent 和刷题教练 Agent。擅长把大原理用小代码讲清，也擅长把项目讲成有量化收益的故事。」
