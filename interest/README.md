# 兴趣（interest/）

> 工作之外，我喜欢折腾的方向。它们往往反哺我的主业。

---

## 1. 把复杂系统讲清楚

- 费曼学习法：学完能讲给别人听，才算真懂。
- 喜欢做「一张图看懂 XX」：架构图、流程图、对比表。
- 本作品集就是这种兴趣的产物。

## 2. 看各种架构设计与开源实现

- 偏爱「nano 级」精简实现：nano-vllm、nano-graphrag、nanobot——用小代码讲清大原理。
- 从 Hermes Agent、X-Plore 这类「整理型作品」里学**知识组织方法**。

## 3. 自己理解后分享出来

- 笔记 → 经验贴 → 简历模板，形成闭环。
- 相信「输出倒逼输入」：写清楚才发现哪里没懂。

## 4. 折腾工具链

- 代理式编程（Claude Code / CodeBuddy）
- 个人知识库（Markdown + 静态站）
- 自动化（cron 类定时任务、脚本化重复活）

---

> 兴趣不是主业的点缀，而是主业的「训练场」。
